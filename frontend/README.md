# Geburtstagsseite

Dies ist ein mit [Next.js](https://nextjs.org) und [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) erstelltes Projekt.

## Erste Schritte

Starte zunächst den Entwicklungsserver:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Öffne anschließend [http://localhost:3000](http://localhost:3000) im Browser.

Du kannst die Seite durch Bearbeiten von `app/page.tsx` anpassen. Die Seite wird während der Bearbeitung automatisch aktualisiert.

Dieses Projekt verwendet [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts), um [Geist](https://vercel.com/font) automatisch zu optimieren und zu laden.
